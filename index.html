06 / n8n · Apps Script · Webhooks · API Sankhya

      
Cadastro Automático de Parceiros

      
Add-on em Google Apps Script lê o XML da NF-e recebido no Gmail e envia ao n8n (self-hosted, protegido por Cloudflare Access), que consulta o parceiro por CNPJ e cadastra, atualiza ou reativa no Sankhya via API.
